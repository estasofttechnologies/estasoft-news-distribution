# Estasoft News Distribution

News sitemaps, partner feeds and pushes for Google News, Microsoft Start, Yahoo News, Apple News, SmartNews and more, with a check on every article, as one free WordPress plugin.

- **Get it from WordPress.org:** <https://wordpress.org/plugins/estasoft-news-distribution/>
- **Author:** [ESTASOFT TECHNOLOGIES](https://www.estasoft.com/)
- **Requires:** WordPress 6.6 or later, PHP 7.4 or later
- **License:** GPL-2.0-or-later (see [LICENSE](LICENSE))

## What this repository is

This repository holds the released plugin files, exactly as they are published on WordPress.org: one tagged commit for each release. Development, tests and internal notes are kept in a private repository, so the history here starts at each release.

Each [release](https://github.com/estasofttechnologies/estasoft-news-distribution/releases) has the plugin as a zip you can install from **Plugins, Add New, Upload Plugin** on any WordPress site.

## Install

1. Install it from the Plugins screen of your site (search for "Estasoft News Distribution"), or
2. download the zip from the [releases](https://github.com/estasofttechnologies/estasoft-news-distribution/releases) page and upload it under **Plugins, Add New, Upload Plugin**.

The full description, FAQ, list of external services and changelog are in [`readme.txt`](readme.txt).

## Bundled library

[Action Scheduler](https://actionscheduler.org/) 3.9.3 is bundled, unchanged, in `vendor/woocommerce/action-scheduler/` (GPL-3.0-or-later, with its own license file in that folder).
